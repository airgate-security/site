# airgate.io

Landing page of Airgate, served by GitHub Pages at https://airgate.io.

Plain HTML and CSS, no build step. English is `index.html`, Russian is `ru/index.html`;
both pages carry the same blocks, edit them together. Fonts are self-hosted in
`assets/fonts` (SIL OFL 1.1), the page makes no requests to other domains.

Local preview: `python3 -m http.server 8000`, then http://127.0.0.1:8000.

Console screenshots in `assets/img` show synthetic data only: no real addresses,
companies or countries.
